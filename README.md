# QazLedger AI

AI accounting agent for Kazakhstan businesses.

## Problem

Accountants spend significant time manually processing bank statements,
identifying counterparties, classifying transactions and creating documents in 1C.

## Solution

QazLedger AI analyzes bank statement transactions and prepares accounting decisions automatically.

The agent can:

- analyze Kaspi Bank statements;
- understand payment purpose and transaction direction;
- identify counterparties;
- classify accounting operations;
- flag uncertain transactions for manual review;
- prepare unposted draft documents in 1C;
- never post accounting documents automatically.

## AI workflow

Bank Statement → QazLedger AI → Decision → Human Review → 1C Draft

## Safety

QazLedger AI follows a human-in-the-loop approach.
Low-confidence transactions are never processed automatically.
